# farewell pet · 산책 지도

반려견 프로필(체급·약·성격)을 먼저 입력하고, 산책로처럼 이어진 지도에서 병원·호텔·유치원·미용실을 골라 조건을 하나씩 대조해 보는 프로토타입입니다.

- 첫 화면(홈): `index.html` — 왼쪽 오늘 하루 기록 · 오른쪽 맞춤 시설 찾기 지도, '캘린더' 탭에서 한 달 기록·평균 산책시간
- 소개·브랜드 이야기: `intro.html`
- 우리 아이 등록(질문 한 개씩 + 건강 고민 + 미니미 꾸미기 + 성격 검사 MCPQ-R): `profile.html`
- 맞춤 시설 찾기 · 필터링 · 상세: `index.html` (예전 주소 `services.html`은 홈으로 이동)
- 보호자 문의함: `inbox.html` / 업체 문의함: `partner.html` (Supabase, 스키마는 `supabase/migrations/`)
- 수의사 1:1 상담: `consult.html` (Supabase 이메일·비밀번호 로그인·실시간 채팅)
- 강아지 앨범·용량·포토북·생애 기록 신청: `album.html`
- 가족 방(셋로그식 10초 영상·사진 공유, 초대 코드, 돌봄시설 임시가족): `family.html`
- 건강토픽(프로필 기반 자동 구독, 몸 부위로 찾기, 토픽→시설 조건 연결): `topics.html`

이메일 계정은 사이트의 로그인·회원가입 창에서 이메일과 비밀번호로 만들고 로그인합니다. 회원가입은 이메일 인증 코드를 확인한 뒤 완료됩니다. Supabase 대시보드의 **Authentication → Providers → Email**에서 이메일 확인(Confirm email)을 켜고, **Authentication → Email Templates → Confirm signup** 본문에 `{{ .Token }}`을 넣어 일회용 코드를 보내도록 설정하세요. 확인 코드의 유효 시간과 발송 제한은 Supabase Auth 설정을 따릅니다. 공용 비밀번호나 인증 우회 문구를 코드·저장소에 넣지 마세요.

### 가족 방 (2026-11-20)
- 가족·함께 키우는 사람은 초대 코드(6자리, 24시간, 한 번)로 들어오고, 누가 돌보든 최대 10초 영상이나 사진을 바로 올립니다. 올리면 가족 방을 열어 둔 다른 가족 화면에 실시간으로 알림이 뜹니다(브라우저 알림을 허용하면 다른 탭에 있어도 알림).
- 돌봄시설에 맡기면 시설을 ‘임시가족’으로 초대합니다. 입실~퇴실 기간에만 읽고 올릴 수 있고, 기간이 끝나면 자동으로 나가집니다. 맡기기 전 글·오늘 기록·돌봄 정보(약·몸무게·성격)를 볼지 보호자가 고릅니다. 시설 계정 하나로 여러 가족 방에 들어갈 수 있고 위쪽에서 방을 고릅니다.
- **로그인하면** Supabase에 저장됩니다: `families`, `family_members`, `family_invites`, `family_posts`, 비공개 버킷 `family-media`(50MB 이하), Realtime. 권한은 모두 RLS로 막습니다(임시가족 기간·열람 범위 포함). 스키마: `supabase/migrations/20261120_family_room.sql` (2026-11-20 프로젝트에 적용함).
  - 초대 코드 사용은 `redeem_family_invite`, ‘지금 아이는’·돌봄 정보는 보호자 기록에서 필요한 것만 요약하는 `family_snapshot`을 씁니다.
- **로그인하지 않으면** 시연 모드입니다. 이 기기 브라우저(localStorage `farewell-pet-family-v1`, IndexedDB `fp-family`)에만 저장하고, 같은 브라우저 탭끼리 BroadcastChannel로 알립니다. 탭마다 ‘시안 보기’ 입장을 다르게 두면 시연할 수 있습니다.
- 앱을 완전히 닫았을 때 오는 푸시 알림은 아직 없습니다(서비스 워커·웹 푸시 필요).

### 건강토픽 (2026-11-20, 시안)
- 프로필의 건강 고민·나이(8살 이상)·먹는 약으로 토픽을 미리 구독하고 이유를 보여 줍니다. 게시글 수와 글은 예시입니다.
- 강아지 그림에서 부위를 누르면 그 부위 토픽이 나오고, 토픽 안에서 ‘맡길 때 볼 조건’으로 산책 지도(호텔·유치원·병원·미용실)로 이어집니다.

### 로그인 없이 쓰기 (2026-11-16)
- 로그인하지 않아도 아이 등록·하루 기록·시설 기록·찜·돌봄 체크리스트를 쓸 수 있고, 이 기기 브라우저(localStorage `farewell-pet-guest-v1`)에 남아 탭이나 브라우저를 닫아도 이어집니다.
- 로그인하면 기기에 남은 기록을 계정으로 옮기고 기기 사본은 지웁니다(`FP.markSignedIn`). 계정에 저장된 기록은 기기에 따로 남기지 않습니다.
- 하루 기록 화면의 ‘이 기기 기록 지우기’로 게스트 기록을 모두 지울 수 있습니다. 공용 컴퓨터에서는 다 쓰고 지워 주세요.
- 수의사 상담과 업체 문의는 여전히 로그인이 필요합니다.

### 하루 기록 (2026-11-16)
- 산책 일기 탭의 첫 화면은 ‘하루 기록’(`daily.js`, `daily.css`)입니다. 밥·산책·배변·영양제·간식·놀이·물·사진 버튼으로 지금 시각에 바로 남깁니다.
- 산책·놀이·물은 애플 피트니스처럼 링으로 채우고, 이번 주 링 줄에서 날짜를 고릅니다. 목표는 견종·체급·나이·체형으로 계산한 권장값에서 시작하고 바꿀 수 있습니다.
- ‘지금 산책 시작’은 카카오맵 위에 경로를 실시간으로 그리고 시간·거리를 잽니다(위치 권한 필요, 없으면 시간만). 카카오맵을 못 불러오면 경로 선만 그립니다.
- 산책 중 대변·소변을 누르면 지도 가운데 핀으로 위치를 정하고, 지도의 배변 아이콘은 끌어서 옮길 수 있습니다. 산책이 끝나면 경로·출발·도착·배변 위치를 지도로 보여 주고, 하루 기록의 산책 경로를 눌러 다시 볼 수 있습니다.
- 기록 시각은 저장하는 순간으로 자동 입력되고, 필요할 때만 ‘시각 바꾸기’로 고칩니다(지난 날짜는 직접 고름).
- 사진은 앱 안 카메라로 바로 찍습니다(전환·앨범 버튼 포함). 카메라를 쓸 수 없으면 기기 카메라/앨범으로 넘어갑니다.
- 사진은 찍은 시각과 산책 시간·거리를 사진에 새겨 ‘그 순간’ 줄에 모읍니다.
- 배변 모양은 동물병원·연구에서 널리 쓰는 퓨리나 대변 점수(Purina Fecal Scoring Chart, 1~7점, 2점이 이상적)를 따릅니다. 보호자마다 판정이 갈릴 수 있어(Cavett 외, J Small Anim Pract 2021, doi:10.1111/jsap.13283) 그림과 ‘집어 올렸을 때’ 설명을 함께 보여 줍니다. 이전 5단계 기록은 7점으로 옮깁니다.
- 대변 색(갈색·초록·노랑주황·회색·붉은 줄·검고 끈적)과 소변 색(연한 노랑·투명·진한 노랑·주황갈색·분홍빨강) 안내는 Hill's·MedVet 등 수의 자료를 따릅니다. 검은 타르 변·피·붉은 소변·소변이 안 나옴은 ‘오늘 바로’, 하루 두 번 넘는 형태 없는 변·회색 변·흰 쌀알은 ‘빨리 상담’, 이틀에 걸쳐 반복된 초록·노랑 변이나 진한 노랑 소변은 ‘지켜보기’로 알립니다. 진단이 아니라 기록·안내용입니다.
- 또래 비교의 ‘상위 %’는 같은 체급 보호자 기록이 20명 이상이면 `daily_walk_rank`로 실제 순위를, 그 전에는 권장 범위를 기준으로 한 추정치를 보여 주고 화면에 추정치라고 적습니다.
- 병원·호텔 등 시설 방문 일기는 ‘시설 기록’ 창으로 옮겼습니다(기존 `diary.js`).
- 로그인한 보호자의 하루 기록은 `daily_logs`에 저장됩니다. `supabase/migrations/20261116_daily_logs.sql`을 SQL Editor에서 실행하세요. 실행 전에는 이 탭에만 저장됩니다.

### 돌봄 기록 (2026-11-12)
- 문의 대화는 `inquiry_messages` 테이블을 씁니다. (같은 프로젝트의 `messages`는 다른 용도로 쓰이고 있어 건드리지 않았습니다.)
- 보호자는 대화에서 돌봄 체크리스트(5~10개, 1~12시간 간격)를 정하고, 업체는 입실·퇴실·체크리스트·사진/영상을 보냅니다.
- 체크리스트 질문은 `checklist.js`의 검수용 목록에서만 고릅니다. Edge Function `checklist-ai`에 `GEMINI_API_KEY` 비밀값을 넣으면 AI가 고르고, 없으면 프로필 규칙으로 고릅니다.
- 업체의 입실·퇴실·체크리스트는 보호자 일기(`diary_entries`)에 자동으로 기록됩니다. 보호자가 일기 화면에서 끌 수 있습니다.
- 로그인한 보호자의 일기는 계정에 저장되고, Edge Function `calendar-feed`로 구글 캘린더 구독 링크를 만들 수 있습니다.
- 사진·영상은 비공개 버킷 `pet-media`(50MB 이하)에 저장되고 1인 기본 500MB입니다. 업체가 보낸 파일은 용량에서 뺍니다.
- 용량 추가·포토북·생애 기록은 결제 연동 전이라 `orders`에 신청만 저장됩니다. 운영자가 확인 후 `status`와 `guardian_settings.quota_bytes`를 바꿉니다.
- 스키마: `supabase/migrations/20261112_care_diary_album.sql`

로그인 세션은 현재 브라우저 탭에만 저장됩니다. 사이트 내부 페이지 이동과 새로고침 중에는 유지되고, 탭을 닫으면 자동으로 종료됩니다. 브라우저 임시 프로필, 찜한 곳, 일기와 AI 대화도 현재 탭에서만 유지되며 탭을 닫으면 초기화됩니다.

호텔·유치원·미용 업체와 요금은 화면 설명용 예시입니다. 병원 3곳은 공개 정보이며, 진료 조건은 병원에 직접 확인해야 합니다.

위치 지도와 길찾기는 카카오맵(`kakaomap.js`)을 쓰며, 카카오 개발자 콘솔에 등록한 도메인에서만 표시됩니다.

로그인하지 않아도 아이 등록 페이지에서 프로필을 만들고 서비스를 쓸 수 있습니다. 로그인 전 기록은 이 기기 브라우저에 남습니다(위 ‘로그인 없이 쓰기’). 로그인한 사용자의 프로필은 계정에 저장되므로 이후 로그인하면 다시 불러옵니다. 아이 정보를 계정별로 저장하려면 `supabase/migrations/20261112_create_pet_profiles.sql`을 사이트에서 사용하는 Supabase 프로젝트의 SQL Editor에서 실행하고 로그인하세요. 로그인한 첫 계정에는 현재 탭의 임시 프로필이 한 번 옮겨지며, 이후에는 계정에 저장된 프로필을 사용합니다. 로그아웃하면 이 기기의 계정 프로필 캐시만 지우며, 계정에 저장된 정보는 유지됩니다. 찜한 곳, 일기와 AI 대화는 현재 탭에서만 유지되며 탭을 닫으면 초기화됩니다.

수의사 상담을 활성화하려면 `supabase/migrations/20261110_create_vet_consultations.sql`도 SQL Editor에서 실행하세요. 수의사는 계정을 만든 뒤 로그인해 프로필과 면허 번호를 제출합니다. 운영자는 면허를 별도로 확인한 뒤 신청자의 `user_id`를 확인하고 승인할 수 있습니다.

```sql
update public.veterinarian_applications
set status = 'approved'
where user_id = '신청자의 auth user UUID';
```

승인 시 수의사 프로필이 자동으로 만들어지며, 수의사가 상담 가능 여부를 켜면 고객 목록에 상담 시작 버튼이 표시됩니다. 거절은 `status = 'rejected'`로 변경합니다. 면허 번호는 공개 프로필에 포함되지 않습니다.

로컬 실행(PowerShell):

```powershell
$env:GEMINI_API_KEY="Google AI Studio에서 발급한 API 키"
node server.cjs
```

브라우저에서 http://localhost:5175 를 열면 AI 상담 버튼을 사용할 수 있습니다. [Google AI Studio에서 Gemini API 키](https://aistudio.google.com/api-keys)를 발급한 뒤 서버 환경 변수 `GEMINI_API_KEY`로 설정하세요. 기본 모델은 응답이 빠르고 가벼운 `gemini-3.5-flash-lite`이며, `GEMINI_MODEL` 환경 변수로 바꿀 수 있습니다. API 키는 브라우저 코드에 넣지 마세요.

Gemini API에는 무료 사용 등급이 있지만 모델과 계정별 사용량 제한이 적용됩니다. 무료 등급에 입력한 콘텐츠는 Google 제품 개선에 사용될 수 있으므로 민감한 개인정보나 건강 정보를 입력하지 않도록 안내하세요. 최신 한도와 조건은 [Gemini API 요금 안내](https://ai.google.dev/gemini-api/docs/pricing)에서 확인하세요.

Vercel은 `vercel.json` 설정으로 HTML/CSS/JS 페이지를 정적으로 배포합니다. GitHub Pages 같은 정적 호스팅은 API 서버를 실행하지 않으므로 AI 상담은 제공할 수 없습니다. AI 상담까지 배포하려면 Node 서버를 별도 호스팅하고 `/api/chat` 요청을 연결해야 합니다. 공개 운영 전에는 사용자별 인증, 요청 제한 및 비용 한도를 추가하세요.

## 전남광주통합특별시 공공데이터

`public-places.js`는 지방행정 인허가 공공데이터(동물병원·동물미용업·동물위탁관리업 CSV)에서 영업 중인 곳만 뽑아 만든 파일입니다. 새 CSV를 받으면 아래처럼 다시 만들면 됩니다.

```
python3 tools/build_public_places.py 동물병원.csv 동물미용업.csv 동물위탁관리업.csv public-places.js
```
